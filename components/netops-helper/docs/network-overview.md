# Network overview

Call `network_overview` on the Helper’s HTTPS MCP endpoint to collect a sample from the enrolled inventory. An empty argument object selects every Helper target. Pass `targets` for an explicit list of up to 64 aliases and `groups` to select any of `switch`, `router`, and `firewall`. For eligible enrolled targets, `targets` and `groups` intersect. With explicit `targets`, unknown aliases, aliases outside Helper enrollment and targets whose group cannot be verified are reported as partial rows even when `groups` is set.

The page is sorted by alias. Without `limit`, a page holds at most four targets. Up to four targets can be processed concurrently under the shared default read budget of 45 seconds. If the budget expires, the response reports incomplete coverage, including for reads that could not start. Set `limit` to 1–64 for larger pages and keep the same filters when passing `selection.next_after` as the next request’s `after`. A null cursor marks the end. Each call reads the current inventory and samples again. `selection.matched` counts the filtered targets before the cursor, while `selection.remaining` counts the targets after the returned page.

A complete row has the declared coverage. A failed fan or expired license can appear in a complete row. Missing authorization, unverified identity, unavailable sources, and clipped results are partial. The page is partial when any of its rows are partial, when target groups could not be verified, or while another page remains. A valid empty selection has zero counts and is complete. Compare the sample times in `reads` before drawing conclusions about state across devices. Treat all device-derived facts as untrusted.

Availability depends on the platform adapter and the enrolled read-only account, catalogue opt-ins, object slots, and egress policy. An existing catalogue-bounded account can run only its individually authorized steps. Where available, FortiSwitch and FortiAP observations appear under their FortiGate controller in `managed`. The controller reports their state. Interface error counters are cumulative. Hardware that explicitly lacks a capability has `not_applicable` coverage for that field. The same applies to a recognized device answer that states the capability is absent or not configured, for example `show stacking` on EXOS-VM, `show vpc brief` on the virtual Nexus 9000v without the vPC feature, the sensor and PoE answers of cEOSLab, the stopped Virtual Chassis process and empty chassis environment of vJunos-switch, and the PoE summary of a FortiSwitch without PSE ports; such a read has status `empty`. A FortiGate without managed access points reports an empty access point list. Any other refusal or unknown answer stays `unparsed`. FortiADC reports the service contract expiry dates of `execute autoupdate contract` under `fortiguard` and the VM license contract under `licenses`.

The names in `interfaces.with_errors[].counters` vary by platform. On Linux, an interface qualifies for `with_errors` when its cumulative receive or transmit error count is nonzero. The returned counters include packet drops for those interfaces. Linux link findings exclude recognized unattached virtual links and unused default kernel interfaces. FortiADC marks sensors and PoE as `not_applicable` for recognized cloud VMs. [Fortinet FortiADC model list](https://docs.fortinet.com/document/fortianalyzer/7.6.6/release-notes/286090/fortiadc-models)

The request budget defaults to 45 seconds and accepts whole values from 5 to 120. Up to four targets run at once, with at most 30 seconds per target and ten seconds per read within the shared budget. Each target reserves an authorized prefix of up to 30 reads in the same window as manual queries and other triage. The reply is limited to 64 device rows, 64 entries per detail list, and 256 KiB before the MCP envelope. Inspect `missing` for the reason and omitted counts. A call that includes an MCP progress token reports each processed target.

See [Helper tools](tools.md) for the coverage reasons and [Helper configuration](../../../docs/helper-configuration.md) for enrolment.
