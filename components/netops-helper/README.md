# Helper engine

This directory contains an internal engine of the single NetOps application. It is not a separately installable or separately released package. Product version and dependencies are declared only in the root pyproject.toml and requirements.lock.

Use the [NetOps quickstart](../../docs/quickstart-1.0.md), [architecture](../../docs/architecture-1.0.md), [support boundaries](../../docs/verified-support.md) and [qualification procedure](../../docs/testing-1.0.md). Engine sources are in src; regression tests and their non-production support fixtures are in tests. Earlier standalone installation, release tooling, images and SBOMs are preserved only in the [historical archive](../../docs/archive/0.x/standalone-layout/README.md).
