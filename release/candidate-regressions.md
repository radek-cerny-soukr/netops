- Auditor visibility versus exit: `test_cli_process_coverage`, JSON/SARIF, inherent/user versus networking/build; vyžaduje exit0 proti exit3 a přesné inherent/actionable gapy, nikoli jen evaluation_complete=false.
- Pravdivé limity a docs/API: `release/tests/test_locate_contract_docs.py`, H `test_locate_endpoint.py` schema/default/deadline/target limit, release klasifikační docs a API testy. Kontrolují konkrétní publikované hodnoty proti kontraktu; nejde o novou redakci sdílených docs mimo rozsah G0b.

Výslovně oddělené maintainer coverage QA (`tests/test_release_gate.py`, viz docs/testing-1.0.md) není součást root `unittest discover` používaného CI. Nezaměňujeme je za proběhlé coverage měření a nesnižujeme coverage floor. V tomto úkolu se měří předepsaná kumulativní regrese, nikoli kvalifikace vydání, ARM ani živá síťová matice.
