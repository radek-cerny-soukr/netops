# NetOps Core engine

Shared SSH transport, credential validation, host-key trust, inventory and schema contracts.

This is an internal engine of the single NetOps 1.0 Docker product. It is not a separately released or installed 1.0 package. Use the [product quickstart](../../docs/quickstart-1.0.md) and [architecture](../../docs/architecture-1.0.md). The source layout preserves the existing measured device and schema contracts.

The [historical 0.x README](../../docs/archive/0.x/components/netops-core/README.md) is a byte-preserved snapshot, not current installation guidance.
