# Historical standalone component layout

This is a byte-preserved snapshot removed from the pre-release NetOps 1.0 source tree. It includes older standalone installation/release instructions and SBOMs that do not describe the single NetOps image. Metadata in the transitional snapshot can already say 1.0.0; it does not declare a separate supported distribution. INDEX.json records the original path and SHA-256 for every file. Current deployment and qualification are documented at docs/quickstart-1.0.md and docs/testing-1.0.md. Never install or publish these archived files as a current release.
